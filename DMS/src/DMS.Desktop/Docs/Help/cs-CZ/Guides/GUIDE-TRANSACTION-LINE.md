# Transakční řádek

Transakce lze spouštět zadáním kódu do horního transakčního řádku.

## Příklady
`QO05`

`QO02 123456`

`QA03 1000012345`

## Navigace
- **F3** se vrací na předchozí obrazovku.
- **F5** znovu načte aktuální transakci.
- **F1** otevře kontextovou nápovědu bez opuštění obrazovky.

Některé transakce podporují spuštění bez parametru a následný výběr hodnoty pomocí přehledu nebo **F4**.
