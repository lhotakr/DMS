# HELP – Dokumentace DMS

Otevírá plné centrum dokumentace přímo v pracovním prostoru DMS.

## Použití
`HELP`

Lze otevřít i konkrétní téma, například `HELP QO02`.

V levé části lze dokumentaci filtrovat a vybírat podle témat a modulů. Pravá část zobrazuje obsah dokumentu a případně tlačítko pro spuštění související transakce.
