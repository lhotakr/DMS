# QASET – Quality nastavení

Správa Quality číselníků a výchozích hodnot.

## Výchozí úkoly zakázek
QASET umožňuje definovat úkoly, které se při založení nové Quality zakázky automaticky zkopírují do zakázky. Výchozí konfigurace obsahuje úkol **Laborka**.

Změna výchozích úkolů nezasahuje zpětně do již založených zakázek.
