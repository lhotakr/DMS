# CLSET – Nastavení klienta

Spravuje nastavení konkrétního DMS klienta a uživatele.

## Funkční klávesy
Lze zapnout nebo vypnout SAP-like funkční klávesy a zobrazování spodní lišty.

## Dokumentace
- **Zobrazovat uživatelskou nápovědu** – povolí kontextové okno přes F1.
- **Zobrazovat technické informace** – doplní do nápovědy technická metadata tématu, kultury a zdroje dokumentu.

Uložení nastavení lze potvrdit pomocí **F8**.
