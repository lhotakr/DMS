# DMS – integrated help

DMS combines an SAP-like transaction line with regular graphical navigation.

## Quick help
- **F1** opens contextual help for the current transaction in a separate window.
- **HELP** opens the complete documentation center inside DMS.
- Links in documentation can start related transactions directly.
