# Transaction line

Start transactions from the command field at the top of DMS.

Examples: `QO05`, `QO02 123456`, `QA03 1000012345`.

- **F3** navigates back.
- **F5** reloads the current transaction.
- **F1** opens contextual help without leaving the screen.
