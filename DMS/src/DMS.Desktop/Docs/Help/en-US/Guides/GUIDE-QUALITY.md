# Quality – basic workflow

1. Create a quality order in [QO01](dms:QO01).
2. DMS copies print-version data and default order tasks such as **Laborka**.
3. Change the order in [QO02](dms:QO02).
4. Use [QO05](dms:QO05) for the order overview.
5. [QATASK](dms:QATASK) combines print-version and order tasks.
6. Release or block the order in [QO06](dms:QO06).

Default order tasks are maintained in [QASET](dms:QASET).
