# DMS function keys

DMS uses consistent SAP-like meanings. A screen exposes only actions that are relevant there.

- **F1** – contextual help
- **F2** – edit
- **F3** – back
- **F4** – value help / selection
- **F5** – refresh
- **F6** – new
- **F7** – previous
- **F8** – execute / save / confirm
- **F9** – next
- **F12** – cancel

Function-key preferences are stored per client in [CLSET](dms:CLSET).
